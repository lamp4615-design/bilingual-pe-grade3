# 學習紀錄（階段 D）

| 檔案／資料 | 來源 | 用途 |
|---|---|---|
| `{單元}_學習項目.json` | `python 工具/build_learning_map.py 單元名`（由教案自動產生） | 該單元的「學習項目庫」：教學目標、新字詞、英語用語，各自首次出現在第幾節、之後哪幾節複習 |
| `weak-points.json` | 欄位定義；實際資料在 Google 試算表「不熟悉清單」 | 老師不熟悉的內容（備課教練產出 JSON → 網站匯入） |
| 試算表「教學進度」 | 網站單節頁「標記已教」 | 哪一節已教 |
| 試算表「教學省思」 | 網站「學習紀錄 → 課後省思」 | 做得好、要調整、下次複習 |
| 試算表「學生評量」 | 學生 iPad 自評與同儕觀察 | 每項目三等第的分佈、每位學生平均 |

## 網站「學習紀錄 → 歷程總覽」怎麼判斷「建議複習」
| 類型 | 條件 |
|---|---|
| 老師 | 不熟悉清單中狀態不是「已熟」 |
| 省思 | 課後省思「下次要複習」有填 |
| 學生 | 某節某評量項目「努力中」佔 40% 以上（至少 3 筆） |
| 螺旋 | 本單元的新字詞／新句型，已教過但最近 2 節以上都沒再出現（最多列 6 項，缺口最久的優先） |

這份建議可一鍵複製，貼進備課教練對話開頭，或在設計下一個單元時作為「複習」欄的素材（階段 E）。
