## 一、研究定位

- 研究問題：國小學科教師推行雙語教學的方式、實施中的挑戰與限制、雙語體育教學後教師遇到的困難與省思。
- 方法：**行動研究**（設計教學方案 → 執行 → 蒐集資料〔課堂表現、教師反思、夥伴回饋〕→ 修正，循環）。
- 研究流程圖：研究準備 → 行動研究（設計→執行→蒐集，**滾動修正**）→ 整理成果。
- 與英語教師及導師**共同備課**、觀課、議課。

> 啟示：本站的「教案 → 備課對話 → 上課 → 反思紀錄 → 修正下一課」即是把這個行動研究循環做成工具。

## 二、理論基礎

### CLIL（內容與語言整合學習）
- 教學以**學科內容為中心**，語言是學習內容的溝通工具（Coyle, 2007）。
- **4Cs**：Content（內容）、Communication（溝通）、Cognition（認知）、Culture（文化）。
- 溝通層的語言三分：
  - **Language of learning**：學習目標必學語言（動作、器材詞彙）
  - **Language for learning**：課堂任務中使用的語言（指令、回應）
  - **Language through learning**：展開過程中較不可預期、協助思考與表達的延伸語言
- 語言比重可依學習者程度、情境、教材調整。

### TPR（全身反應教學法，Asher）
- 「刺激—反應」：教師用外語下指令＋動作示範，學生以**肢體動作回應**，不強迫用外語回應；肢體反應時間愈短，聽覺理解程度愈高（區國良等，2022）。
- 課室用語（教室管理）與課程內容語言（如 Touch the ball）都用 TPR；先預想高頻班級經營用語，**搭配手勢**（例：Eyes on me 指眼睛→指自己）。
- 降低焦慮、提升動機，適合英語剛啟蒙的低年級。

## 三、課程設計原則（論文 p.35–37、p.51–55）

1. **體育為主、不犧牲活動時間**：不可把體育時間挪去教英語；目標是在**保持體育學科內容完整**下發展語言能力。
2. 設計單元：先確定年級、先備知識、主題 → 訂教學目標 → 列預計學會的**語言**（字彙、溝通句型、領域專業字彙）→ **體育與英語教師共同備課**，避免因偏重英語而影響體育目標。
3. **4Cs 落地範例**（飛盤，論文 p.35）：
   - Content：依十二年國教健體領綱素養導向所編教材（Ga-I-1 走跑跳與投擲遊戲）
   - Communication：目標語言 throw、frisbee；句子 Aim for the target、Which throw is easier/more difficult
   - Cognition：先跟老師示範練習，再小組分開練習、**小組討論策略**發展高層次思考
   - Culture：賽前小組討論戰術、遊戲中解決問題與人際溝通、養成規律運動習慣
4. **課程設計理念五點**（論文 p.51）：①簡單明瞭的指導（示範＋動作）②小組活動③基本技能為主（大肌肉）④趣味性與遊戲化⑤身體素質訓練（靈活、速度、平衡）。
5. **素養導向設計四概念**（表 3-3，以反應高手為例）：以**學生為主體**（自我探索嘗試，教師引導）／**情境化、生活連結**／**核心素養培養**／**教師角色轉換**（不直接糾正，以提問引導：「你剛剛閃避時，身體重心在哪裡？有沒有其他方法更快更安全？」）。
6. 教學情境與生活連結：語言教學應著重設計活動、讓學生藉實踐與參與建構知識（Karaman, 2021），促進所學遷移到日常生活。

## 四、評量與回饋原則（論文 p.36–37）

- 以**形成性評量**為主，**即時、建設性回饋**；多元評估方式。
- CLIL 雙語體育評量重點是 4Cs 的「學科內容」；例：聽到指令（Aim for the target）→做出動作，動作要有一定**準確性**，體育技能不可因語言學習而被忽略。
- 語言與溝通的評量：看學生是否**聽懂教師英語指令**，並運用詞彙與句型與同學交流（發出指示、分享觀點、參與討論、提問）。**不用總結性筆試。**
- 學生若無法理解英語指示，**教師適時用中文解釋**，確保評量流程被理解。
- 研究資料來源：學生學習觀察紀錄表、教師日誌、夥伴回饋、家長問卷（英語學習經驗、偏好活動、對雙語態度）。

## 六、三年級調整原則（老師已指示：依論文方式調整，以下為本站預設，請核對）

| 面向 | 一年級（論文） | 三年級（預設調整） |
|---|---|---|
| 課綱階段 | 第一學習階段 I | **第二學習階段 II**（見 `01`） |
| 語言輸出 | 以 TPR 單詞／短指令為主，不強求學生說 | 在「聽懂→做」之外，增加**學生說**：字詞（2-II-3）、教室用語（2-II-4）、簡易句型（2-II-6） |
| 句型 | 命令式（Stop! Pass!） | 加入問答：`Can you ___? / Yes, I can. / I can ___.`；同伴互動：`Pass to me. / I'm open.` |
| 認知（Cognition） | 簡單比較（Soft / Hard） | **策略討論**：3d-II-1/2 練習策略、合作與競爭策略；`Which way is faster?` |
| 動作技能 | 單一動作 | **聯合性動作**（3c-II-1）：如帶球＋傳球＋射門連結 |
| 教師角色 | 示範、指令 | 提問引導、讓學生自己發現與修正（論文表 3-3「教師角色轉換」） |
| 中英比例 | 低（中文說明、英文口令） | 略增：口令與鼓勵全英文，策略討論允許中文 |
| 評量 | 觀察聽懂指令的反應 | 觀察反應＋**學生英語使用紀錄**（說出字詞／句型的次數與正確度） |
| 時間 | 每週 2 堂 × 40 分 | 實際節數、週數待老師確認 |

## 七、論文留給本站的啟示（對應五項需求）

1. **教案**：沿用「CLIL 4Cs + TPR + 素養導向」框架。
2. **備課對話**：教師語句運用 ＝ 練習腳本的種子；學生以 TPR 動作回應為主，三年級加簡短口說。
3. **歷程記錄**：論文的「學生學習觀察紀錄表、教師日誌、夥伴回饋」＝本站的紀錄欄位設計依據。
4. **螺旋式複習**：論文的單元由簡到繁、每節承接上節暖身（足球樂第 2–7 節的暖身都延續前一節）。
5. **滾動修正**：每堂課後的反思→修正下一課，是行動研究核心。
