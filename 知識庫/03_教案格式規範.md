# 教案格式規範（臺中市雙語課程教案設計格式）

> 來源：`足球樂(1).docx`（老師與夥伴的一年級教案，7 節）；113 年度優等（大甲國小，六年級羽球）、佳作（文武國小，**三年級**拋投）示範教案。
> 格式由林子斌教授團隊研發；表格中英文皆可，鼓勵逐年增加英文。

### B. 教學設計理念 Rationale
範例寫法：兩三段，點出教學法（TPR、CLIL）、聽—做—說、生活情境與團隊合作；可條列「雙語連續性與循序漸進」。
**「教學原理」小節**列 TPR（動作＋聲音／練習／觀察）與 CLIL 4Cs。

### C. 核心素養對應（**邏輯鏈第一、二環**）
| 欄位 | 內容 |
|---|---|
| 總綱 | 如 E-A1 身心素質與自我精進；E-C2 人際關係與團隊合作（或 A2、C2） |
| 領綱 | 健體-E-xx 完整條文；若含英語領域，加列 英-E-B1 |
| 校本素養指標 | 無則免填 |

### D. 學習重點（**邏輯鏈第三、四環**）
| 欄位 | 內容 |
|---|---|
| 學習表現 | 編碼＋條文，多條；佳作範例另分「健體領域」「英語文領域」兩段列出 |
| 學習內容 | 編碼＋條文；英語領域可列 Ac-II-1、B-II-1 等 |

### E. 學生準備度 Readiness
- 學科準備度：認知／技能／情意
- 英語準備度：如「能理解簡單課室英語」「能用英語數到 20」「能聽懂 Eyes on me / Are you ready?」

### F. 單元學習目標
- **Content**（學科內容目標，條列「學生能…」）
- **Language** 三層：
  1. Language **of** learning（學科核心字詞：Pass, Dribble, Defender…）
  2. Language **for** learning（課堂任務所需語言：Pass to me, Slow down, Spread out…）
  3. Language **through** learning（互動中延伸的語言：Nice pass, I'm open…）

### G. 中／英文使用時機
表格：教師／學生 × When／Where。例：活動說明用中文、問候與口令用英文、分組討論可用中文。

### H. 教學方法、策略、資源、評量
- 教學方法：CLIL、TPR、素養導向體育教學
- 教學策略：互動式提問、小組討論…
- 教學資源及輔助器材
- 評量方法／**評量規準 Rubrics**（範例未填，**本站要補**）
- 議題融入：最多兩項，無則免填

### I. 教學流程（每節一張表，三階段）
| 階段 | 內容 |
|---|---|
| 準備階段 Preparation | 暖身操（教師口令）、與主題相關的感受活動 |
| 發展階段 Development | Part 1、Part 2…；每個 Part 含「活動流程介紹」「教師語句運用（英文句）」「※教學提醒」 |
| 總結階段 Summary | 總結與收心提問、預告下一堂 |
| 另有 | 時間欄（範例以 8／12／15／5 分鐘分配：暖身 8、Part 1 12、Part 2 15、總結 5＝40 分） |

### J. 參考資料、教學歷程與省思
（範例 docx 的最後兩欄：教學歷程與省思 → **對應本站「學習歷程紀錄」**）

## 二、範例教案的觀察（供生成教案時模仿）

1. **一節＝暖身 8 + Part1 12 + Part2 15 + 總結 5（分鐘）**；每節兩個活動（Part）。
2. **「教師語句運用」**是核心產出：短句、祈使句、可配動作的指令（Ready… Go! / Stop the ball! / Slow down / Soft touch / Switch! / Next group, get ready!）。
3. 每節都有**中文提醒**（※），針對安全、常見錯誤、差異化。
4. 單元由簡到繁：**控球 → 轉彎 → 傳球 → 傳球＋跑位 → 射門 → 策略傳球 → 3v1**，每節承接上一節暖身（螺旋式的雛形）。
5. 三年級佳作的做法（文武國小）：領綱同時列健體＋英語；教學模式 **Game–Practice–Game**；英語準備度寫明已會的句型（Line up. / Are you ready? / Ready go! / Eyes on me. / Warm up.）。
6. 範例**未做**但本站要補：評量規準、各活動的 CLIL 4C 標示、TPR 流程標示（聽→做→說）。

## 三、本站教案的「邏輯性檢核表」（待與老師確認後作為生成規則）

| # | 檢核項目 | 通過條件 |
|---|---|---|
| 1 | 總綱 → 領綱一致 | 領綱素養的第一個字母/編號與總綱項目對得上（A1→E-A1…） |
| 2 | 學習表現皆取自第二學習階段 | 編碼為 `xx-II-x` |
| 3 | 學習內容皆取自第二學習階段 | 編碼為 `Xx-II-x` |
| 4 | 每個學習表現都有活動承接 | 活動表有「對應學習表現」欄 |
| 5 | 每個學習內容都有活動承接 | 同上 |
| 6 | 每個單元目標可回溯 | 目標 ↔ 學習表現 ↔ 學習內容 |
| 7 | 英語目標不超出 II 階段 | 對照 `02_課綱_英語` |
| 8 | 活動不超出課綱範圍 | 無對應條文的活動標記為「課綱外」，須刪除或調整 |
| 9 | 評量與學習表現對應 | 評量規準由學習表現轉寫 |

## 四、領綱核心素養的挑選規則（系統自動執行）

領綱核心素養**不是先選好再填入**，而是由學習表現推導，確保邏輯鏈一致：

| 若教案學習表現含… | 對應領綱素養 | 理由 |
|---|---|---|
| 3c-II-x 技能表現、4d-II-x 運動實踐、2c-II-3 主動參與、1c-II-x | 健體-E-A1（含 總綱 A1） | 動作技能與運動習慣的養成 |
| 3d-II-x 策略運用、1d-II-x 技能原理（策略／練習方法） | 健體-E-A2（含 總綱 A2） | 探索、思考、解決運動問題 |
| 4c-II-x 運動計畫（擬定個人／小組練習計畫） | 健體-E-A3（含 總綱 A3） | 規劃與創新 |
| 2c-II-1/2 規則與團隊合作、3b-II-2 人際溝通、2d-II-2 觀賞者角色 | 健體-E-C2（含 總綱 C2） | 團隊合作與公平競爭 |
| 2c-II-1 遵守比賽規則（強調規範與公平） | 健體-E-C1（含 總綱 C1） | 運動道德與規範 |
| 雙語課的英語口說／指令（教案英語目標） | 健體-E-B1（含 總綱 B1）＋英-E-B1 | 符號運用與溝通 |
| 2d-II-3 欣賞多元身體活動、Ib/Ic 民俗舞蹈 | 健體-E-B3 或 E-C3 | 美感／多元文化 |

原則：**每份教案 2–3 條領綱素養**，且每一條都必須有至少一條學習表現支持；雙語體育課通常固定含 **B1**（因英語溝通）。
