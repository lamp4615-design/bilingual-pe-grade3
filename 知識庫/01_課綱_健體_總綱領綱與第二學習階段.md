## 一、課綱邏輯鏈（所有教案必須依此順序推導）

```
總綱核心素養 (A1~C3)
   └─ 領綱核心素養 (健體-E-xx，國小 E)
        └─ 學習表現 (類別 1認知/2情意/3技能/4行為，編碼如 3c-II-1)
             └─ 學習內容 (主題 A~I，編碼如 Hb-II-1)
                  └─ 單元學習目標 → 教學活動 → 評量
```

編碼規則：學習表現 `類別 + 次項目 + 學習階段 + 流水號`，例 `3c-II-1` = 技能 / 技能表現 / 第二階段 / 第1條。
學習內容 `主題 + 次項目 + 學習階段 + 流水號`，例 `Hb-II-1` = 競爭類型運動 / 陣地攻守性球類 / 第二階段 / 第1條。
第二學習階段 = 國小 3–4 年級（羅馬數字 II）。

## 二、核心素養：總綱 → 領綱（國小 E）

| 總綱面向 | 總綱項目 | 領綱核心素養（國小） |
|---|---|---|
| A 自主行動 | A1 身心素質與自我精進 | **健體-E-A1** 具備良好身體活動與健康生活的習慣，以促進身心健全發展，並認識個人特質，發展運動與保健的潛能。 |
| | A2 系統思考與解決問題 | **健體-E-A2** 具備探索身體活動與健康生活問題的思考能力，並透過體驗與實踐，處理日常生活中運動與健康的問題。 |
| | A3 規劃執行與創新應變 | **健體-E-A3** 具備擬定基本的運動與保健計畫及實作能力，並創新思考方式，因應日常生活情境。 |
| B 溝通互動 | B1 符號運用與溝通表達 | **健體-E-B1** 具備運用體育與健康之相關符號知能，能以同理心應用在生活中的運動、保健與人際溝通上。 |
| | B2 科技資訊與媒體素養 | **健體-E-B2** 具備應用體育與健康相關科技及資訊的基本素養，並理解各類媒體刊載、報導有關體育與健康內容的意義與影響。 |
| | B3 藝術涵養與美感素養 | **健體-E-B3** 具備運動與健康有關的感知與欣賞的基本素養，促進多元感官的發展，在生活環境中培養運動與健康有關的美感體驗。 |
| C 社會參與 | C1 道德實踐與公民意識 | **健體-E-C1** 具備生活中有關運動與健康的道德知識與是非判斷能力，理解並遵守相關的道德規範，培養公民意識，關懷社會。 |
| | C2 人際關係與團隊合作 | **健體-E-C2** 具備同理他人感受，在體育活動和健康生活中樂於與人互動、公平競爭，並與團隊成員合作，促進身心健康。 |
| | C3 多元文化與國際理解 | **健體-E-C3** 具備理解與關心本土、國際體育與健康議題的素養，並認識與包容文化的多元性。 |

> 範例教案（足球樂）與 113 年度示範教案皆以 **E-A1 + E-C2** 為主；文武國小三年級佳作教案用 **E-A2 + E-C2**（再加英語領綱 英-E-B1）。三年級偏策略與合作的課，**E-A2、E-C2** 通常比 E-A1 更貼切。

## 六、一年級 → 三年級 對照（論文原設計 → 三年級調整）

| 論文（第一階段 I） | 三年級（第二階段 II） | 差異重點 |
|---|---|---|
| 1c-I-1 認識身體活動的基本動作 | 1c-II-1 認識身體活動的動作技能 | 由「基本動作」到「動作技能」 |
| 1c-I-2 認識基本的運動常識 | 1c-II-2 認識身體活動的傷害和防護概念 | 增加安全防護概念 |
| 2c-I-1 表現尊重的團體互動行為 | 2c-II-1 遵守規範與比賽規則；2c-II-2 增進團隊合作、友善互動 | 由尊重到規則與合作 |
| 3c-I-1 表現基本動作與模仿的能力 | 3c-II-1 表現聯合性動作技能 | 由單一動作到**連結動作**（如帶球＋傳球） |
| 3c-I-2 表現安全的身體活動行為 | 3c-II-2 探索運動潛能、表現正確的身體活動 | 加入探索與正確性 |
| （一年級無對應） | **3d-II-1/2 運用練習策略、遊戲的合作和競爭策略** | 三年級新增：策略思考 |
| 4d-I-1 願意從事規律身體活動 | 4d-II-1/2 培養規律運動習慣並分享益處、參與提高體適能 | 由「願意」到「分享與參與」 |
| Hb-I-1 簡易拍、拋、接、擲、傳、滾及踢、控、停 | Hb-II-1 …帶球、追逐、停球之**時間、空間及人與人、人與球關係攻防概念** | 由動作到**攻防概念** |
