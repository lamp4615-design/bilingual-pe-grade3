# Apps Script 後端與教師後台：建置步驟（約 15 分鐘，由老師操作）

一份程式、兩個部署：

| 部署 | 誰能開 | 用途 |
|---|---|---|
| **學生用**（誰可以存取：所有人） | 學生 iPad、網站 | 取名單、送出自評／互評。靠「班級代碼」。 |
| **教師後台**（誰可以存取：只有我自己） | 只有你，Google 登入 | 登記成績、看各班成績與表現、分組。**不用任何密碼**，身分就是你的 Google 帳號。 |

網站本身**沒有任何老師密碼**。唯一的祕密是學生用的 `CLASS_CODE`。

## 第一次建置
1. 建立 Google 試算表，命名「雙語共學資料庫」。
2. 試算表選單：**擴充功能 → Apps Script**。
3. 把 `Code.gs` 整份貼進去（取代預設內容）。
4. 左側檔案清單旁的 **「＋」→ HTML**，檔名輸入 `Console`（不用加 .html），把 `Console.html` 整份貼進去。
5. 左側 **專案設定（齒輪）→ 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」**，回編輯器打開 `appsscript.json`，內容換成本資料夾的 `appsscript.json`（多了一個 `userinfo.email` 權限，後台用它確認你是擁有者）。
6. 函式選單選 **setup**，按「執行」並授權。完成後試算表會有 9 個工作表：學生名單、學生評量、教師評量、不熟悉清單、教學進度、教學省思、複習排程、體育成績、分組紀錄。
7. **專案設定 → 指令碼屬性 → 新增**：`CLASS_CODE` ＝ 學生用的班級代碼（不要用太好猜的）。**不需要 TEACHER_PIN**，有舊的可以刪掉。
8. **部署 → 新增部署作業 → 網頁應用程式**
   - 第一個（學生用）：執行身分 **我**、誰可以存取 **所有人** → 部署，複製網址，貼到網站「設定」或 `網站/config.js` 的 `APPS_SCRIPT_URL`。
   - 第二個（教師後台）：再「新增部署作業」一次，執行身分 **我**、誰可以存取 **只有我自己** → 部署，複製網址，貼到網站「設定」的「教師後台網址」或 `config.js` 的 `TEACHER_CONSOLE_URL`。
9. 用手機或電腦開「教師後台」網址，登入你的 Google 帳號（擁有這份試算表的那個）。第一次到「名單」分頁各貼一次甲班、乙班名單。

## 之後更新程式
改了 `Code.gs` 或 `Console.html` 要重新貼上，然後 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本**。**兩個部署都要更新**，網址不變。

## 從舊版（有老師密碼）升級
重貼 `Code.gs`、新增 `Console` 檔案、換掉 `appsscript.json`，再執行一次 **setup**（會補上「班級」欄與新工作表，舊資料視為甲班），然後依步驟 8 新增「只有我自己」的部署，並把學生用部署更新成新版本。

## 教師後台功能
- **登記成績**：選班級、項目、日期、第幾次，逐人輸入。同一天同一次重送＝更正。
- **成績總覽**：各班平均／最好／最後、各班平均變化、個人與之前最佳的比較、CSV 下載、學生自評／互評統計。
- **分組**：依成績分組，可選「能力均衡（蛇行）」「同質分層」「師徒配對」「完全隨機」「沿用原本的隊」，可指定組數或每組人數、接力棒次、缺席名單、手動微調，存起來下一堂課「載入沿用」。
- **個人表現**：每位學生一列，各項目並排：最近／最佳成績、班內名次、與班平均的差、較前次與首測以來的進步；可依性別篩選、改用「同班同性別」比名次，並整合學生自評。
- **課堂評分**：選班級與節次，逐人選三等第（努力中／達成／優異）與備註，資料存在「教師評量」工作表，重存會覆蓋。評量項目從網站的教案資料讀取。
- **運動會選手**：甲班、乙班各自依成績挑人互相 PK。內建三種賽制（全班 80 公尺不排隊型，不在此處理）：
  - **100 公尺競賽**：每班 2 男 2 女。
  - **400 公尺接力**：每班 4 男 4 女，共 8 棒、每棒約 50 公尺，棒次可選男女交替等排法。
  - **班級接力**：每班 16 人，不分性別，純看速度排棒次（預設另列 2 位候補）。
  人數、候補、依據項目（預設 100 公尺跑）、取歷史最好或最近一次都可改；可設「不參加」與「一定要上場」，產生後可 ↑↓ 調棒次、「換人」，並存檔、載入、下載 CSV、列印。
- **名單**：每班貼一次，格式 `座號,隊,性別,暱稱`（後面可省略、順序可換），性別填「男」或「女」；也可逐位用下拉選單補性別。**性別是挑 100 公尺競賽與 400 公尺接力選手、同性別名次要用的**（班級接力不分性別）。

## 資料表（工作表）
| 工作表 | 用途 |
|---|---|
| 學生名單 | 座號、隊、暱稱、班級、性別 |
| 學生評量 | iPad 自評／同儕觀察的每一筆紀錄（含班級） |
| 體育成績 | 日期、班級、項目、座號、次別、成績、單位 |
| 教師評量 | 課堂評分：單元、節、班級、座號、項目、等第、備註（每人每節每項目一列） |
| 賽事選手 | 運動會選手名單：每次儲存一個「名單ID」，每位選手一列（班級、座號、性別、正選／候補、棒次、成績） |
| 分組紀錄 | 每次分組一個「分組ID」，每位學生一列（組別、棒次、當時成績） |
| 不熟悉清單／教學進度／教學省思／複習排程 | 舊版功能的資料表（網站端目前已停用，尚未移到教師後台） |

## 安全提醒
- 學生網址只能「取名單」「送出評量」。成績、分組、評量統計只有教師後台讀得到。
- 教師後台的每個功能都再次確認「目前登入者＝試算表擁有者」，別人即使拿到網址也進不去。
- 試算表內是學生資料，請只分享給自己。後端只存座號與隊別，不存真實姓名。
- 班級代碼外流時，到指令碼屬性改掉即可（QR code 要重印）。

## 學生端呼叫方式（給前端）
`POST` 學生用網頁應用程式網址，body 為 JSON 字串，**不要加 Content-Type header**（避開預檢請求）：
```js
fetch(URL, { method: 'POST', body: JSON.stringify({ action: 'roster', classCode: '你的班級代碼' }) })
```
回傳 `{ ok: true, data: ... }` 或 `{ ok: false, error: '...' }`。

## 從舊版升級（加入性別與運動會選手）
重貼 `Code.gs` 與 `Console.html`，執行一次 **setup**（只會在「學生名單」最右邊補「性別」欄、建立「賽事選手」工作表，舊資料不動），再到兩個部署各「管理部署作業 → 編輯 → 新版本」。接著到後台「名單」分頁補上每位學生的性別。
