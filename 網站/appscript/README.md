# Apps Script 後端：建置步驟（約 15 分鐘，由老師操作）

## 先準備的三樣東西
| 項目 | 說明 |
|---|---|
| Google 帳號 | 用來放試算表與 Apps Script |
| Anthropic API Key | 到 console.anthropic.com 建立（與 claude.ai 訂閱是**分開計費**，需先儲值，建議設用量上限）。只有「備課教練」對話會用到；沒有 Key，其他功能照常運作 |
| 兩組密碼 | **老師密碼 TEACHER_PIN**（自己用）、**班級代碼 CLASS_CODE**（學生 iPad 用，例如 4 位數） |

## 步驟
1. 建立新的 Google 試算表，命名「雙語共學資料庫」。
2. 試算表選單：**擴充功能 → Apps Script**。
3. 把 `Code.gs` 整份貼進去（取代預設內容），存檔。
4. 在編輯器上方函式選單選 **setup**，按「執行」，並授權。完成後試算表會多出 7 個工作表：學生名單、學生評量、練習紀錄、不熟悉清單、教學進度、教學省思、複習排程。
5. 左側 **專案設定（齒輪）→ 指令碼屬性 → 新增指令碼屬性**：
   | 名稱 | 值 |
   |---|---|
   | `CLASS_CODE` | 學生用的班級代碼 |
   | `TEACHER_PIN` | 老師密碼 |
   | `ANTHROPIC_API_KEY` | 你的 API Key |
   | `MODEL`（選填） | 預設 `claude-sonnet-5-5`；想省費用可填 `claude-haiku-4-5-20251001` |
6. **部署 → 新增部署作業 → 類型：網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「網頁應用程式網址」（以 `https://script.google.com/macros/s/.../exec` 結尾）。
7. 把這個網址交給我（或寫進 `網站/config.js` 的 `APPS_SCRIPT_URL`）。**網址本身不是密碼**；真正的保護是 TEACHER_PIN 與 CLASS_CODE。
8. 到「學生名單」工作表確認 18 人與分隊（預設 1–18 號、每 3 人一隊，6 隊）；暱稱欄可留空或填代號，**不建議填真實全名**。

## 之後更新程式
改了 `Code.gs` 要重新貼上，並 **部署 → 管理部署作業 → 編輯 → 版本：新版本**，網址不變。

## 安全提醒
- API Key、老師密碼、班級代碼**只放在指令碼屬性**，不放 GitHub、不放前端。
- 學生 iPad 只能呼叫「取名單」與「送出評量」；其他功能（教練對話、紀錄、省思）需要老師密碼。
- 試算表內是學生評量資料，請只分享給自己。
- 後端只存座號與隊別，不存真實姓名。

## 資料表（工作表）說明
| 工作表 | 用途 |
|---|---|
| 學生名單 | 座號、隊、暱稱 |
| 學生評量 | iPad 自評／同儕觀察的每一筆紀錄 |
| 練習紀錄 | 備課教練對話紀錄 |
| 不熟悉清單 | 老師不熟悉的英語與情境（累計次數、狀態） |
| 教學進度 | 哪個單元哪一節已教 |
| 教學省思 | 課後省思（做得好／要調整／下次複習） |
| 複習排程 | 螺旋複習的項目與下次複習日（階段 E 使用） |

## 呼叫方式（給前端）
`POST` 網頁應用程式網址，body 為 JSON 字串，**不要加 Content-Type header**（避開瀏覽器預檢請求）：
```js
fetch(URL, { method: 'POST', body: JSON.stringify({ action: 'roster', classCode: '1234' }) })
```
回傳 `{ ok: true, data: ... }` 或 `{ ok: false, error: '...' }`。
