## 教學設計理念

本單元以三年級學生為對象，重新教接棒：右手接、左手傳，接棒的手掌心朝上、大拇指朝內；看著傳棒者的速度決定何時起跑；傳棒不減速、接到棒一定換手；兩班同場時依「先到先內道」站位；跑完往內或往外離場，不在跑道逗留。教學以 TPR（聽—做—說）為起點，每節只用少量常用的英語口令（Hand! Pass! Go! Keep running! Switch! Inside! Outside!），反覆使用到變成習慣。課程採 CLIL 4Cs：以接棒技術與安全規則為內容（Content），以口令為溝通（Communication），以判斷來人速度、調整助跑記號、處理突發狀況培養思考（Cognition），並以同學互相提醒、公平競爭與運動會流程呈現文化（Culture）。評量以形成性為主，結合教師觀察、學生 iPad 自評與同儕觀察。

## 學生準備度

**學科**
- 認知：知道跑步前要暖身、跑步時要避免碰撞
- 技能：能進行跑、停的基本動作
- 情意：願意與同學合作並遵守團隊規則

**英語**
- Super Fun 1 全冊視為已學：數字 1–10、Line up, please.、Stand up / Sit down、Good job. / Try again.、strong / tall / short、happy / sad、Are you tired? – Yes, I am. / No, I'm not.、How are you? – I'm fine.

## 單元學習目標

### Content
- **C1** 學生能用右手接棒（掌心朝上、大拇指朝內）、左手傳棒，在跑動中不減速完成交接，並在接到棒後換手　（表現 3c-II-1；內容 Ga-II-1）
- **C2** 學生能依來人的速度用記號判斷助跑時機，並依結果調整，在突發狀況中做出應變　（表現 3d-II-1、3d-II-2；內容 Ga-II-1）
- **C3** 學生能與夥伴合作、互相提醒（如喊 Switch!）並在比賽中鼓勵他人　（表現 2c-II-2、3d-II-2；內容 Ga-II-1）
- **C4** 學生能遵守站位（接棒靠內、傳棒靠外）、先到先內道、離場與掉棒規則，並了解學校運動賽會的流程　（表現 2c-II-1；內容 Cb-II-2、Ga-II-1）
- **C5** 學生能以英語口令（Hand! Pass! Go! Keep running! Switch! Inside! Outside!）引導與提醒夥伴　（表現 3b-II-2；內容 Ga-II-1）
- **C6** 學生能在跑前做出暖身與伸展動作，並遵守暖身常規　（表現 2c-II-1；內容 Bc-II-1）

### Language

- **Language of learning**：baton（接力棒）；pass（傳）；switch（換）；inside（內側）；outside（外側）
- **Language for learning**：Hand!（傳棒者提醒夥伴伸手）；Pass!（把棒子放進手裡）；Go!（起跑）；Keep running!（不要停）；Switch!（提醒隊友換手）；Inside! / Outside!（站位與離場方向）；Are you ready? – Yes, I am!
- **Language through learning**：Good job! / Try again! / Great teamwork!；Nice pass! / Nice take!

*新字詞：* baton、pass、switch、inside、outside　*新句型：* Are you ready? – Yes, I am!

- 方法：CLIL、TPR、素養導向體育教學

### 學生 iPad 評量設計

- **原則**：學生以 iPad 操作，介面簡單（圖示＋少量中英文）；自評用三張表情（😀🙂💪），同儕觀察用三顆星並可選一句英文鼓勵（Nice pass! / Good job! / Great teamwork!）。資料回傳 Google 試算表，供教師與『學習紀錄』使用。
- **對應**：表情與星等對應評量規準：😀／⭐⭐⭐＝優異；🙂／⭐⭐＝達成；💪／⭐＝努力中（學生版用語，不作為成績）。

## 教學流程 Teaching Procedures


### 第 1 節　Hand! Pass! 接棒的手與傳棒

場地：體育館　器材：接力棒 6 支、手型檢核卡、角錐、右手貼紙、iPad

**複習（螺旋）**：Super Fun 1：Raise your hand. / Work in pairs.；Super Fun 1：Good job. / Try again.

**準備階段 Preparation（8 分）暖身 Warm up**

動態暖身（原地踏步、抬膝、手腕與肩膀繞圈），用 Raise your hand 帶出「右手」，並在右手貼上貼紙。左右手一律用中文說明。

教師語句：Let's warm up! / Raise your hand. / Wrist circles. / Good job!

對應：2c-II-1｜Bc-II-1｜C6

**發展階段 Development（12 分）Part 1 認識 baton 與接棒的手**

展示 baton，教師示範接棒手型：右手向後伸直，掌心朝上、大拇指朝內、虎口張開成 V 字，不回頭。全班先空手練習，聽到 Hand! 就伸出右手。兩人一組一前一後，後面的人左手握棒子尾端，喊 Hand! 後，把棒子從上往下放進前面夥伴的虎口並說 Pass!，每人先練 3 次。

教師語句運用：This is a baton. / Hand! / Pass! / Work in pairs. / Good job!　學生回應：Baton. / Hand! / Pass!

- TPR：聽 聽 Hand! 與教師示範　→　做 伸出右手、接棒、把棒子放進手裡　→　說 傳棒者說 Hand! Pass!
- CLIL 4C：內容 接棒的手型與下壓式交接；溝通 baton、pass（新詞）、hand（已學）；認知 比較「手掌朝下」與「V 字虎口朝上」哪個棒子比較穩；文化 輕輕交給夥伴，不丟棒
- 對應：3c-II-1、3b-II-2｜Ga-II-1｜C1、C5
- ※左右手用中文說明，手型用圖卡與示範。棒子不可丟或甩。接棒者不回頭，手臂固定不晃。新詞 baton、pass 都配實物與動作，不要求拼寫。

**發展階段 Development（15 分）Part 2 站著傳棒檢查站**

9 組 2 人，6 組練習、3 組當觀察員，輪流。練習組站著傳棒：傳棒者左手握尾端，先喊 Hand!，再說 Pass!。觀察員用手型檢核卡檢查：掌心朝上、大拇指朝內、沒有回頭，並用 iPad 做同儕觀察。每組練 5 次後交換角色與組別。

教師語句運用：Hand! Pass! / Try again. / Next team, go! / Well done!　學生回應：Hand! / Pass! / Good job!

- TPR：聽 聽夥伴的 Hand!　→　做 伸手接棒或把棒子放進手裡　→　說 喊 Hand! Pass!，完成後互說 Good job!
- CLIL 4C：內容 穩定交接與檢查手型；溝通 Hand! Pass!；認知 用檢核卡判斷夥伴的手型對不對；文化 輪流與互相檢查
- 對應：3c-II-1、3d-II-1、2c-II-2｜Ga-II-1｜C1、C2、C3
- ※這節完全不跑也不走，先把手型做準。觀察員只檢查手型，不評論人。

**總結階段 Summary（5 分）**

提問：What is this?（baton）；接棒的手要怎麼擺？（用手比給大家看）；傳棒的人說什麼？（Hand! Pass!）

預告：下一堂要邊走邊傳棒。　Exit：兩人面對面各說一句：Hand! / Pass!；iPad 自評。

**學生評量**：自評 動作技能｜同儕觀察 英語互動

第 1 節結束 End of session 1

### 第 2 節　Walk and Pass 走著傳

場地：體育館　器材：接力棒 6 支、角錐、地面兩條線（模擬跑道）、口令圖卡、iPad

**複習（螺旋）**：第 1 節：Hand! / Pass! 與接棒的手型；Super Fun 1：Good job. / Try again.

**準備階段 Preparation（8 分）暖身 Warm up**

動態暖身加上手腕與肩膀繞圈，用慢走複習聽口令（Go / Stop / Walk），並再練一次右手向後伸直。

教師語句：Let's warm up! / Walk. / Stop. / Go!

對應：2c-II-1｜Bc-II-1｜C6

**發展階段 Development（12 分）Part 1 站位與不回頭**

兩人一組在一條跑道線上：接棒者站在線的內側、背對傳棒者，右手向後伸直；傳棒者站在外側、同方向跟著慢慢走，到接棒者旁邊時喊 Hand!，把棒子放進對方手中並說 Pass!。接棒者不回頭，手一直伸著等。

教師語句運用：Walk. / Hand! / Pass! / Stop. / Good job!　學生回應：Hand! / Pass! / Good job!

- TPR：聽 聽 Walk. 與 Hand!　→　做 慢走並完成交接　→　說 傳棒者喊 Hand! Pass!，完成後互說 Good job!
- CLIL 4C：內容 同一跑道內接棒者靠內、傳棒者靠外；溝通 Walk. / Hand! / Pass!；認知 想想為什麼接棒的人不能回頭看（回頭會放慢、偏離方向）；文化 信任夥伴
- 對應：3c-II-1、2c-II-1、3b-II-2｜Ga-II-1｜C1、C4、C5
- ※站位口訣用中文：接棒靠內、傳棒靠外，傳棒者的左手剛好遞到接棒者的右手。原因用中文說明，不用英文解釋。

**發展階段 Development（15 分）Part 2 走著傳到終點**

9 組 2 人，6 組練習、3 組觀察，輪流。傳棒者從起點走到接棒者旁，傳完棒後接棒者走到終點錐。練習組全程慢走，不跑。觀察員檢查三件事：①站位內外對不對 ②接棒者有沒有回頭 ③傳完有沒有繼續走。

教師語句運用：Walk slowly. / Hand! Pass! / Next team, go! / Well done!　學生回應：Hand! / Pass! / Good job!

- TPR：聽 聽 Walk slowly. 與夥伴口令　→　做 慢走並完成交接　→　說 喊 Hand! Pass!，完成後互說 Good job!
- CLIL 4C：內容 慢走時的連續動作；溝通 Hand! Pass! / Next team, go!；認知 先慢再快的練習策略；文化 輪流與互相檢查
- 對應：3c-II-1、3d-II-1、2c-II-2｜Ga-II-1｜C1、C2、C3
- ※先「穩」再「快」：這節只走不跑。教師用中文強調「慢慢做準，下一節才會快」。

**總結階段 Summary（5 分）**

提問：接棒的人站哪一側？傳棒的人站哪一側？；Hand! 是誰說的？Pass! 呢？；Are you tired?

預告：下一堂要慢跑著傳，還要學接到棒以後的一個新動作。　Exit：兩人面對面各說一句：Hand! / Pass!；iPad 自評。

**學生評量**：自評 動作技能｜同儕觀察 規則與合作

第 2 節結束 End of session 2

### 第 3 節　Keep Running! Switch! 慢跑傳與換手

場地：體育館　器材：接力棒 6 支、角錐、口令圖卡、換手示範圖卡、iPad

**複習（螺旋）**：第 2 節：Walk. / Hand! / Pass!，接棒靠內、傳棒靠外；第 1 節：接棒的手型

**準備階段 Preparation（8 分）暖身 Warm up**

動態暖身後慢跑一圈，複習 Walk. / Stop. / Go!，並用 Keep running! 帶出「不要停」。

教師語句：Let's warm up! / Go! / Keep running! / Stop.

對應：2c-II-1｜Bc-II-1｜C6

**發展階段 Development（12 分）Part 1 慢跑傳，傳完再多跑**

兩人一組在跑道線上慢跑：接棒者靠內、傳棒者靠外。傳棒者喊 Hand!、Pass! 時不減速，傳完再多跑 3 到 5 步，教師喊 Keep running!；之後兩人往場邊走，離開跑道。

教師語句運用：Go! / Hand! Pass! / Keep running! / Stop. / Good job!　學生回應：Hand! / Pass! / Keep running!

- TPR：聽 聽 Go! 與 Keep running!　→　做 慢跑交接並多跑幾步　→　說 喊 Hand! Pass! Keep running!
- CLIL 4C：內容 傳接時不減速、傳完再多跑幾步；溝通 Keep running!；認知 比較「傳完就停」與「再多跑幾步」哪一種比較不會撞到後面的人；文化 為後面的隊友著想
- 對應：3c-II-1、2c-II-1、3b-II-2｜Ga-II-1｜C1、C4、C5
- ※這節開始教離場：跑完先多跑幾步再慢慢走，往場邊離開，不在跑道上停留。

**發展階段 Development（15 分）Part 2 接到棒要換手 Switch!**

6 隊（每隊 3 人）慢跑連續傳：第 1 人左手握棒傳給第 2 人的右手；第 2 人接到後要把棒子換到左手，再傳給第 3 人。場邊等待的隊友看到有人接到棒就喊 Switch! 提醒。掉棒的人自己撿，不回頭搶，說 Try again. 再繼續。

教師語句運用：Switch! / Hand! Pass! / Keep running! / Try again. / Well done!　學生回應：Switch! / Hand! / Pass! / Try again.

- TPR：聽 聽隊友喊 Switch!　→　做 把棒子換到左手　→　說 喊 Switch! Keep running!
- CLIL 4C：內容 接到棒後換手、連續傳棒；溝通 Switch!；認知 想想為什麼要換手（下一次要用左手傳）；文化 同學互相提醒，不責怪
- 對應：3c-II-1、2c-II-2、3b-II-2｜Ga-II-1｜C1、C3、C5
- ※換手是最容易掉棒的地方：換手時眼睛看前方、手臂不亂甩，握棒尾端留一大段給下一位。掉棒時誰掉誰撿。

**總結階段 Summary（5 分）**

提問：接到棒以後要做什麼？（Switch!）；傳完棒要立刻停嗎？（Keep running!）；掉棒了怎麼辦？

預告：下一堂要學什麼時候開始跑。　Exit：每隊說出一個提醒隊友的口令：Switch! / Keep running!；iPad 自評。

**學生評量**：自評 動作技能｜同儕觀察 英語互動

第 3 節結束 End of session 3

### 第 4 節　Ready? Go! 助跑時機

場地：操場　器材：接力棒 6 支、標記錐 12 個、策略記錄板、口令圖卡、iPad

**複習（螺旋）**：第 3 節：Keep running! / Switch!；第 2 節：Hand! / Pass! 與站位

**準備階段 Preparation（8 分）暖身 Warm up**

動態暖身加上短距離加速跑 2 次，並用 Are you ready? – Yes, I am! 複習起跑口令。

教師語句：Let's warm up! / Are you ready? / Go! / Good job!

對應：2c-II-1｜Bc-II-1｜C6

**發展階段 Development（12 分）Part 1 記號一到就 Go!**

傳棒者從約 15 公尺外跑來。接棒者站在起跑點，回頭看一次來的同學，起跑後就只看前方。教師在接棒者前方約 2 到 3 公尺放一個標記錐：傳棒者跑過標記，接棒者立刻出發。接棒者出發後手向後伸直，傳棒者喊 Hand! 再 Pass!。每組練 3 次。

教師語句運用：Are you ready? / Go! / Hand! Pass! / Keep running! / Good job!　學生回應：Yes, I am! / Go! / Hand! / Pass!

- TPR：聽 聽 Are you ready? 與 Go!　→　做 看到記號就出發並伸手　→　說 回答 Yes, I am! 並喊 Go!
- CLIL 4C：內容 用記號決定助跑時機；溝通 Are you ready? – Yes, I am! / Go!；認知 判斷來的同學跑多快；文化 信任與等待
- 對應：3c-II-1、3d-II-1、3b-II-2｜Ga-II-1｜C1、C2、C5
- ※記號距離先從 2 到 3 公尺開始，是起點不是答案；接棒者只回頭看一次，之後不再看。

**發展階段 Development（15 分）Part 2 自己調記號**

6 隊（每隊 3 人），輪流當傳棒者、接棒者、記錄員。每次傳接後記錄員在策略記錄板記：太早（接棒者出發太早，傳棒者追不上）、剛好、太晚（接棒者還沒跑起來，傳棒者被迫減速）。來的同學跑得快，記號往遠放；跑得慢，往近放。每隊至少調整記號 2 次，最後說明為什麼這樣調。

教師語句運用：Are you ready? / Go! / Switch! / Try again. / Great teamwork!　學生回應：Yes, I am! / Go! / Try again.

- TPR：聽 聽隊友的口令　→　做 調記號再試一次　→　說 喊 Go! Try again.
- CLIL 4C：內容 依速度調整助跑記號；溝通 Go! / Try again.；認知 用「太早／剛好／太晚」判斷並調整；文化 小組合作決定，不責怪
- 對應：3d-II-1、3d-II-2、2c-II-2、3b-II-2｜Ga-II-1｜C2、C3、C5
- ※討論用中文。強調「同一個人今天跑得快，記號就放遠一點」，沒有一個固定的標準答案。

**總結階段 Summary（5 分）**

提問：來的同學比較快，記號要放近還是放遠？；Are you ready?；為什麼接棒的人只能回頭看一次？

預告：下一堂要在跑道上加入兩班同場的站位。　Exit：每隊用一句話說自己調了什麼：Go! / Try again.；iPad 自評。

**學生評量**：自評 練習與策略｜同儕觀察 規則與合作

第 4 節結束 End of session 4

### 第 5 節　Inside! Outside! 站位與讓道

場地：操場　器材：接力棒 6 支、標記錐、粉筆、隊色背心、抽籤卡、口令圖卡、iPad

**複習（螺旋）**：第 4 節：Are you ready? – Yes, I am! / Go!；第 3 節：Keep running! / Switch!；第 2 節：接棒靠內、傳棒靠外

**準備階段 Preparation（8 分）暖身 Warm up**

動態暖身後慢跑，教師喊 Inside! 就靠跑道內側，喊 Outside! 就靠外側，Stop. 就停。

教師語句：Let's warm up! / Inside! / Outside! / Stop.

對應：2c-II-1｜Bc-II-1｜C6

**發展階段 Development（12 分）Part 1 跑完怎麼離場**

兩人一組慢跑傳棒。傳完棒後多跑幾步，再依自己所在的位置離開：在內圈的往內走，在外圈的往外走，離開前先看後方，走到等待區，不在跑道上停留。等待接棒的同學站在等待區的線後面，不站進跑道。

教師語句運用：Go! / Hand! Pass! / Keep running! / Inside! / Outside!　學生回應：Inside! / Outside! / Hand! / Pass!

- TPR：聽 聽 Inside! Outside!　→　做 傳棒後依位置離場　→　說 喊出自己離場的方向
- CLIL 4C：內容 離場方向與等待區；溝通 Inside! / Outside!；認知 判斷自己現在在內圈還是外圈；文化 為他人的安全著想
- 對應：2c-II-1、3c-II-1、3b-II-2｜Ga-II-1｜C4、C1、C5
- ※離場是安全守則，每次練習都要做。沒有走到等待區的人，下一次不能接棒。

**發展階段 Development（15 分）Part 2 抽籤跑道與先到先內道**

兩隊對抗（以隊色分），先抽籤決定第一或第二跑道。第 1 棒到第 2 棒各自站抽到的跑道。從第 2 棒到第 3 棒起，接棒者回頭看一次：哪一隊的傳棒者先跑過來，該隊的接棒者可以站內道，另一隊站外道。如果別隊的接棒者已經出發，內道空了，就可以站進內道。換道只能在自己出發前，並看清楚有沒有人。同一條跑道內，接棒者仍靠內側，傳棒者靠外側。

教師語句運用：Are you ready? / Inside! / Outside! / Go! / Great teamwork!　學生回應：Yes, I am! / Inside! / Outside! / Go!

- TPR：聽 聽夥伴喊 Inside! Outside!　→　做 判斷並站到正確跑道　→　說 喊 Inside! Outside! Go!
- CLIL 4C：內容 先到先內道；溝通 Inside! / Outside!；認知 觀察哪一隊先到並決定站位；文化 公平競爭與禮讓
- 對應：2c-II-1、3d-II-2、2c-II-2｜Ga-II-1｜C4、C2、C3
- ※這是比賽中最容易碰撞的地方：換道一定要在出發前，絕不在跑動中切到別人前面。

**總結階段 Summary（5 分）**

提問：跑完怎麼離開？（內圈往內、外圈往外）；哪一隊的接棒者可以站內道？；為什麼不能在跑道上停下來？

預告：下一堂有情境卡，還有模擬比賽。　Exit：每隊說出一條站位規則，用 Inside! 或 Outside! 開頭；iPad 自評。

**學生評量**：自評 規則與合作｜同儕觀察 動作技能

第 5 節結束 End of session 5

### 第 6 節　Team Race! 隨機應變與模擬賽

場地：操場　器材：接力棒 6 支、標記錐、隊色背心、情境卡 8 張、抽籤卡、秒錶 3 個、iPad

**複習（螺旋）**：第 1 到 5 節全部口令：Hand! / Pass! / Switch! / Keep running! / Go! / Inside! / Outside!

**準備階段 Preparation（8 分）暖身 Warm up**

動態暖身後快問快答：教師做動作，學生搶說對應的口令（伸手 → Hand!、換手 → Switch!）。

教師語句：Let's warm up! / Are you ready? / Hand! / Switch!

對應：2c-II-1｜Bc-II-1｜C6

**發展階段 Development（12 分）Part 1 情境卡：怎麼辦？**

每隊抽一張情境卡：①棒子掉了 ②對手比我們先到 ③接棒的同學還沒到位 ④站錯跑道。小組用中文討論 2 分鐘，再用英語口令演一遍給大家看。

教師語句運用：Work in groups. / Try again. / Keep running! / Well done!　學生回應：Switch! / Inside! / Outside! / Try again.

- TPR：聽 聽情境卡與夥伴口令　→　做 演出處理方式　→　說 用口令提醒夥伴
- CLIL 4C：內容 比賽中的應變；溝通 全部口令；認知 遇到狀況時先看、再決定；文化 不責怪夥伴
- 對應：3d-II-2、2c-II-1、3b-II-2｜Ga-II-1｜C2、C4、C5
- ※沒有標準答案，只要不碰撞、不停在跑道上、隊友彼此提醒就好。

**發展階段 Development（15 分）Part 2 模擬運動會**

運動會流程圖卡：集合 → 抽籤 → 比賽 → 互相鼓勵 → 頒獎。先進行 2 場四人小隊對抗，再用全班合成 16 人大隊接力試跑一次。賽後兩隊互相擊掌說 Great teamwork!。

教師語句運用：Are you ready? / Go! / Great teamwork! / Good job!　學生回應：Yes, I am! / Go! / Great teamwork! / Good job!

- TPR：聽 聽哨音與夥伴口令　→　做 完成比賽　→　說 喊 Go! 並鼓勵對手 Great teamwork!
- CLIL 4C：內容 接力比賽與運動會流程；溝通 Are you ready? – Yes, I am! / Go! / Great teamwork!；認知 應用前五節的技術與規則；文化 公平競爭、為對手加油
- 對應：3c-II-1、2c-II-2、2c-II-1｜Ga-II-1、Cb-II-2｜C1、C3、C4
- ※比賽後先安排離場與等待區，再公布結果。贏了不炫耀，輸了互相鼓勵。

**總結階段 Summary（5 分）**

提問：今天哪一個口令最有用？；遇到狀況時，你最先做什麼？；What can you do better?

預告：單元結束，之後準備運動會。　Exit：每人說出一個最有用的口令；iPad 自評（4 題）。

**學生評量**：自評 動作技能、練習與策略、規則與合作、英語互動｜同儕觀察 動作技能

第 6 節結束 End of session 6
