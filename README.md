# 雙語體育共學站（三年級）

陪伴備課、共創教案、記錄學習歷程。設計者：李宇翔。

| 資料夾 | 內容 |
|---|---|
| `知識庫/` | 課綱（總綱、領綱、學習表現、學習內容）、論文教學原則、格式規範、先備英語、生成規則 |
| `教案/` | 每個單元一份 JSON（資料來源）與 Markdown |
| `對話練習/` | 每堂課的生活情境雙語對話與模擬學生腳本（階段 C） |
| `學習紀錄/` | 已教內容、不熟悉清單、複習排程（階段 D、E） |
| `工具/` | 教案邏輯檢核 `validate_lesson.py` |
| `網站/` | 前端（GitHub Pages）；後端為 Google Apps Script（階段 F） |
| `參考資料/` | 原始 PDF／docx（未納入 git） |

進度：A 資料盤點 ✅　B 教案範本與生成規則 ✅　首份教案：接力賽（8 節，草稿）　C 備課對話 ✅（接力賽 8 節）　D 學習紀錄　E 螺旋複習　F 網站
